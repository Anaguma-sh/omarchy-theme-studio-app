First desktop release of Omarchy Theme Studio.

- Guided workflow and advanced palette editing.
- Local wallpaper palette generation and installed-theme starting points.
- Optional connection to your own OpenAI-compatible AI provider or local server.
- Three consistent previews, hex values and text contrast checks.
- Portable theme archives, local editable projects and AppImage distribution.
- Confirmed theme application, backups, undo and optional VS Code/Cursor IDE sync.

Download the x64 AppImage, allow it to run as a program and open it. No developer tools are required. Requires modern x86_64 Omarchy for desktop application; design and export are available without it.

Automated checks cover palette contrast, export, preservation of editor settings, failed-apply rollback, undo conflicts and AI response validation. Desktop appearance and live provider responses need user verification. Cloudroom and additional app-specific repair integrations are not part of this first release.
